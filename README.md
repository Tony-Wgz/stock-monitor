# 大单监控 Pro

A 股实时监控与分析工具，**单文件网页，双击即用**，无需服务器、无需安装依赖。

## 功能

| 页签 | 内容 |
|---|---|
| 主力加速榜 | 沪深主板 5 分钟主力资金加速排名，异动提醒 |
| 大盘温度 | 七指数、涨跌家数、涨停/跌停、成交额、两融、行业资金流、5 日主线、风格轮动 |
| 量化选股 | 4 种策略（主力进攻/放量突破/超跌反弹/缩量低吸）+ 财务排雷 |
| 盯盘明细 | 腾讯逐笔成交，收盘后可回看当日大单 |
| 个股技术面 | MACD / KDJ / RSI / BOLL / MA，Canvas 绘图 |
| 个股档案 | 财务趋势、经营概况、13 项雷区体检、龙虎榜机构席位、十大流通股东、北向持股、公告新闻 |
| 数据源自检 | 逐条通道可用性检测 |

## 数据来源

东方财富公开接口（push2 / push2his / datacenter-web）+ 腾讯行情。
全部为网页端公开接口，无密钥、无账号、无收费依赖。

## 已知边界

- 东财日频报表（全市场快照、行业资金流）在**收盘后若干小时**才更新，盘中自动切换为实时全扫
- 涨跌停按板别上限近似判定（主板 10% / ST 5% / 双创 20% / 北交所 30%），非交易所权威口径
- 北交所不在选股池内
- 本工具仅做数据整理，不构成投资建议

## 使用

直接打开 `index.html`，或访问 GitHub Pages 地址。

手机打开后可「添加到主屏幕」，像 App 一样使用。
